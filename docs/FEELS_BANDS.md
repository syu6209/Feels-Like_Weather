# 체감 구간과 옷차림 추천 근거

## 1. 기준 지표: 체감온도

Open-Meteo 의 `apparent_temperature` 를 사용합니다. 기온에 습도·풍속·일사를 반영한 체감온도로,
겨울에는 바람(풍속냉각), 여름에는 습도(열지수)의 영향이 반영됩니다.

## 2. 7개 체감 구간 (추운 → 더운 순, 선형)

| 구간 | 기본 범위 (체감) | 대표색 | 설문 선택지 |
|---|---|---|---|
| 강추위 | -10° 미만 | `#3D5AFE` 인디고 | 매우 추웠음 |
| 추움 | -10° ~ 4° | `#2E86DE` 파랑 | 추웠음 |
| 쌀쌀함 | 4° ~ 12° | `#4FC3F7` 하늘색 | 쌀쌀했음 |
| 선선함 | 12° ~ 20° | `#26BFA6` 민트 | 선선했음 |
| 따뜻함 | 20° ~ 26° | `#FFB300` 앰버 | 따뜻했음 |
| 더움 | 26° ~ 32° | `#FF7043` 주황 | 더웠음 |
| 무더움 | 32° 이상 | `#E53935` 빨강 | 무더웠음 |

브리핑 문구의 핵심 단어(예: "쌀쌀하게")는 대표색과 흰색이 흐르는 브러쉬 그라데이션으로 표시됩니다.

## 3. 분기점 근거

| 분기점 | 근거 |
|---|---|
| **-10°** 강추위/추움 | 기상청 겨울철 체감온도 단계: 관심(-10℃ 이상) / **주의(-25℃ ~ -10℃ 미만)** / 경고(-45℃ ~ -25℃ 미만) / 위험(-45℃ 미만). -10℃ 미만부터 노출 피부 저체온 위험이 안내됩니다. |
| **4°** 추움/쌀쌀함 | 국내에서 널리 쓰이는 '기온별 옷차림' 지표에서 4℃ 이하는 패딩·두꺼운 코트·목도리 구간. UTCI 0~9℃ '약한 추위 스트레스'. |
| **12°** 쌀쌀함/선선함 | 기온별 옷차림 지표: 9~11℃ 트렌치코트·점퍼, 12~16℃ 재킷·가디건 — 겉옷이 가벼워지는 지점. |
| **20°** 선선함/따뜻함 | 기온별 옷차림 지표: 20~22℃ 얇은 가디건·긴팔. UTCI 9~26℃ '열 스트레스 없음' 구간의 중간. |
| **26°** 따뜻함/더움 | UTCI(Universal Thermal Climate Index) 26~32℃ '중간 더위 스트레스' 시작. |
| **32°** 더움/무더움 | UTCI 32~38℃ '강한 더위 스트레스' 시작. 기상청 폭염주의보(일 최고체감온도 33℃ 이상 2일 지속 예상)와 근접. |

UTCI 등급 (Bröde et al. / Jendritzky et al.): >46 극한 더위, 38~46 매우 강한 더위, 32~38 강한 더위, 26~32 중간 더위,
9~26 스트레스 없음, 0~9 약한 추위, -13~0 중간 추위, -27~-13 강한 추위, -40~-27 매우 강한 추위, <-40 극한 추위.

> UTCI 와 apparent temperature 는 계산식이 다른 지표이므로, UTCI 경계는 "어느 온도대부터 사람이 스트레스를 느끼는가"에 대한 참고값으로 사용했습니다.
> 이 차이와 개인차는 아래 '내 체감 보정'으로 메웁니다.

## 4. 내 체감 보정 (`FeelsLearner`)

- 설문에서 예보 구간 p 와 다른 구간 r 을 고르면, 그 시간의 체감온도 t 쪽으로 사이의 분기점을 **절반씩** 이동합니다.
  - r > p (예상보다 따뜻하게 느낌) → 분기점 p+1..r 을 `t - 0.5°` 쪽으로 낮춤
    예) 18°가 '선선함'인데 '따뜻했음' → '따뜻함' 시작 온도 20° → 18.8° (20 + 0.5 × (17.5 − 20))
  - r < p (예상보다 춥게 느낌) → 분기점 r+1..p 를 `t + 0.5°` 쪽으로 높임
- 분기점 사이 최소 간격 1° 를 유지해 구간 순서는 절대 뒤집히지 않습니다.
- 같은 시간대에 다시 응답하면 이전 응답을 덮어쓰고, 전체 응답을 시간순으로 재생해 분기점을 다시 계산합니다.
- '내 기준' 프로필의 옷차림 추천과 체감 보정 예보 카드는 이 보정된 구간을, 나머지 프로필은 기본 구간을 사용합니다.

## 5. 브리핑 문구

- 구간별 4~5개 문구, 무작위 노출
- 한 번 노출한 구간의 문구는 1시간 동안 고정 (`Briefings.PIN_DURATION_MILLIS`), 이후에는 직전과 다른 문구를 고름

## 6. 연령대별 옷차림 근거

공식 기준은 없으므로 아래 자료를 조합했습니다.

| 연령대 | 근거와 반영 |
|---|---|
| 성인 | 기온별 옷차림 지표(28℃↑ 민소매·반팔 / 23~27 반팔·얇은 셔츠 / 20~22 얇은 가디건·긴팔 / 17~19 니트·맨투맨 / 12~16 재킷 / 9~11 트렌치코트 / 5~8 코트·히트텍 / 4℃↓ 패딩)을 7개 구간에 맞춰 재구성 |
| 유아 | 미국소아과학회(AAP, HealthyChildren.org): "같은 환경의 어른보다 한 겹 더" 입히기 → 추운 구간에서 내의·방한 우주복 추가. 끈이 걸릴 위험이 있는 목도리 대신 넥워머. 6개월 미만은 선크림보다 그늘·모자·얇은 긴소매 |
| 아동 | 활동량이 많아 땀이 나기 쉬우므로 벗고 입기 쉬운 겉옷(바람막이·경량 패딩) 위주, 우천 시 우비 |
| 중장년 | CDC: 나이가 들면 체온 조절 능력과 추위·더위 감각이 떨어져 저체온증·온열질환 위험 증가 → 추운 구간은 내의·모자·목도리, 더운 구간은 통풍 잘 되는 밝은 옷과 수분 섭취 안내 |

### 날씨 조건 아이템 (활동 시간 기준)

필요한 아이템은 목록 **맨 위**(강조 + 이유 표시), 필요 없는 아이템은 목록 **맨 아래**(흐리게)에 놓입니다.

| 아이템 | 필요 조건 |
|---|---|
| 우산 | 활동 시간 최대 강수확률 40% 이상, 강수량 0.5mm 이상, 또는 비 예보 |
| 우비 (유아·아동) | 우산이 필요할 때 |
| 장화 | 강한 비(코드 65/81/82/95 등) 또는 누적 10mm 이상, 또는 눈 |
| 모자 | 자외선 지수 3 이상(WHO: 차단 필요) 또는 더운 날 |
| 선글라스 | 자외선 지수 6 이상(WHO: 높음), 유아 제외 |
| 선크림 | 자외선 지수 3 이상 |
| 물병 | 더움 이상 구간 |
| 핫팩 | 추움 이하 구간 |
